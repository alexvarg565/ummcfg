# UMMCFG — Tactical Mech Roguelike

**Status:** Playable Combat Prototype | Active Development

UMMCFG is a turn-based tactical mech roguelike I'm developing in Godot as my first independent game project.

The idea is to build your own company of pilots and mechs, take on missions, fight enemy machines and creatures, and gradually expand your company.

Right now, I'm focusing on building a solid tactical combat system while learning more about game development, pixel art, and software engineering.

## Current Features

The prototype currently includes:

- **Grid-Based Combat:** Turn-based movement and attacks on a small tactical battlefield.
- **Initiative System:** Tracks turn order, active units, and upcoming turns.
- **Mech Combat:** Multiple player-controlled mechs fighting enemy units.
- **Enemy AI:** Enemies select targets, calculate movement paths, and execute attacks.
- **Enemy Intent:** Visual indicators communicate planned enemy actions.
- **Terrain Obstacles:** Rocks, structures, and scrap occupy battlefield tiles and block movement.
- **Mission Objectives:** Elimination battles and settlement defense encounters where players protect a generator.
- **Combat UI:** Unit information, health, available actions, and battle results.

These systems are part of an early prototype and are still being refined.

## Technologies

- **Engine:** Godot 4.2.2
- **Programming:** GDScript
- **Pixel Art:** LibreSprite
- **Version Control:** Git and GitHub

## Getting Started

1. Install Godot 4.2.2.
2. Clone or download this repository.
3. Open Godot and select **Import**.
4. Navigate to the project's `project.godot` file.
5. Open the project and run it through the editor.

This repository contains a development prototype rather than a finished game release.
